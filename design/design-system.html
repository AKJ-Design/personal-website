Field Notes & Wayfare

One token vocabulary and one set of structural rules, bound twice. The website and the iOS app look nothing alike — and that's the point. What they share is the grammar underneath: what an accent is for, what gets set in mono, what a hairline is made of.

The rule that matters

read this one
Invariant

The accent does all interactive work. Links, focus rings, selection, marker hover, filled controls, card accents, the live strip's labels. If a thing is interactive it wears the accent; if it wears the accent it should be interactive.

The moment a second colour starts doing interactive work, the thread is dead and the identity goes with it. This is why semantic colour is held separate below — and why, in Field Notes Light, --ok is deliberately a different green from --accent, so "green means success" can never collide with "green means interactive".

Hairlines

A hairline is the accent at low alpha — never a grey. This is the single biggest reason both themes read warm and deliberate rather than default. Field Notes uses 20% for rules and 10% for internal dividers; Wayfare uses 16%, transcribed from Theme.swift's --panel-line and not a free choice. Selection sits at 24% so it stays clearly above the rule weight — otherwise selected text reads as a box rather than a highlight.

Space Grotesk ships no italic. Never set font-style: italic on display type — the renderer fakes an oblique and it reads as a bug. Use weight, size, or the accent for emphasis. Wayfare's Newsreader does have a true italic, and the design leans on it.

Radius — the one honest disagreement

The only structural value the themes differ on. Field Notes is square (0); Wayfare keeps the 12/16/20 scale. Rounded corners on a survey sheet read soft; square corners on iOS read un-native. Both are right in place — style against --radius-card, never a literal.

Working rules

the short version

Style against tokens

Never a literal hex. A theme is a re-binding of names; a literal is a value that can't be re-bound.

Mono for facts

Times, dates, counts, money, status, IDs. With tabular-nums wherever digits stack.

One signature element

The website's is the live strip. Wayfare's is the day timeline. One per surface, not two.

65ch measure

Running text never runs wider. Applies in documents as much as on screen.

Don't add a second accent

The thread is the identity. A second interactive colour halves it and doubles the decisions.

Don't grey the hairlines

They're the accent at low alpha. A neutral grey rule is the fastest way to make this look like a default template.

Don't fake an italic

Space Grotesk has none. Emphasise with weight, size or colour.

Don't put muted-2 on body copy

It's a label colour. At body sizes it fails AA in both themes.
